# 旋轉體體積：圓盤與圓環法 (Discs and Washers)

> **一句話核心定義**：圓盤與圓環法是將平面圖形繞旋轉軸旋轉所得立體，透過「**垂直於旋轉軸**」切割出圓形薄盤（Disc）或中空圓環（Washer），再累加積分求得精確總體積的方法。

## 核心概念與運作原理

- **微元幾何形態**：
  - **圓盤（Disc）**：旋轉區域緊貼旋轉軸，橫截面為完整實心圓，微元體積 $\Delta V = \pi [r(x)]^2 \Delta x$。
  - **圓環（Washer）**：旋轉區域與旋轉軸有空隙，橫截面為中空同心圓，微元體積 $\Delta V = \pi \left[ (R_o(x))^2 - (R_i(x))^2 \right] \Delta x$。
- **變數選取判別法則**：
  - **繞水平軸旋轉**（如 $x$ 軸或 $y = k$）：垂直切片為鉛直線，微元厚度為 $\Delta x$，對 **$x$ 積分**。
  - **繞鉛直軸旋轉**（如 $y$ 軸或 $x = h$）：垂直切片為水平線，微元厚度為 $\Delta y$，對 **$y$ 積分**。

| 方法名稱 | 幾何特徵 | 微元厚度 | 積分微元表達式 $dV$ |
| :--- | :--- | :--- | :--- |
| **圓盤法 (Disc)** | 實心無洞，截面為圓 | $\Delta x$ 或 $\Delta y$ | $\pi [r]^2 \, dx$ |
| **圓環法 (Washer)** | 內部挖空中空環 | $\Delta x$ 或 $\Delta y$ | $\pi \left( R_{\text{outer}}^2 - R_{\text{inner}}^2 \right) dx$ |

## 公式與範例

### 1. 標準計算公式
- **繞水平軸（$y = k$）旋轉**：
  $$V = \int_{a}^{b} \pi \left( [R_o(x) - k]^2 - [R_i(x) - k]^2 \right) dx$$
- **繞鉛直軸（$x = h$）旋轉**：
  $$V = \int_{c}^{d} \pi \left( [R_o(y) - h]^2 - [R_i(y) - h]^2 \right) dy$$

### 2. 典型範例（Worksheet 6.2 範例）
**題目**：求拋物線 $y = -x^2 + 4x + 12$ 與直線 $y = 7$ 所圍區域，繞直線 $y = 7$ 旋轉所得體積。
**解法**：
1. 求交點：$-x^2 + 4x + 12 = 7 \implies x^2 - 4x - 5 = 0 \implies x = -1, 5$。
2. 切片垂直於旋轉軸 $y = 7$，為實心圓盤，半徑為：
   $$r(x) = (-x^2 + 4x + 12) - 7 = -x^2 + 4x + 5$$
3. 建立定積分：
   $$V = \int_{-1}^{5} \pi (-x^2 + 4x + 5)^2 dx = \pi \int_{-1}^{5} (x^4 - 8x^3 + 6x^2 + 40x + 25) dx$$
   $$= \pi \left[ \frac{x^5}{5} - 2x^4 + 2x^3 + 20x^2 + 25x \right]_{-1}^{5}$$

## 常見誤區與重點提醒

- **切勿將半徑相減後平方**：
  - ❌ 錯誤：$\pi (R_o - R_i)^2$（這算出來只是外厚度平方，不是環形面積）
  - ✅ 正確：$\pi (R_o^2 - R_i^2)$
- **分段曲線陷阱**：
  - 若在積分區間內，上界或下界曲線發生更替，必須將積分區間拆分為多個子積分（如 Worksheet 6.2 第 3(b) 題）。
