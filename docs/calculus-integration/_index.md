# 微積分積分應用 (Applications of Integration)

> **分類概述**：本主題整理 Math 102A 單變數微積分在幾何圖形計算上的應用。包含平面封閉區域面積、旋轉體體積之切片法（圓盤/圓環）與柱殼法。

## 知識點清單 (Knowledge Units)

- **[6.1 曲線間面積與切片法 (Areas Under Curves)](./areas-under-curves.md)**
  - 垂直切片（$dx$ 積分）與水平切片（$dy$ 積分）之抉擇準則。
- **[6.2 旋轉體體積：圓盤與圓環法 (Discs and Washers)](./disk-washer-method.md)**
  - 垂直於旋轉軸的截面切割法，實心與中空結構之微元體積。
- **[6.3 旋轉體體積：柱殼法 (Cylindrical Shells)](./cylindrical-shells.md)**
  - 平行於旋轉軸的薄壁圓柱切片，克服難以逆解函數時之求積技巧。

## 學習順序推薦
1. 先熟練 **6.1 面積切片** 中的上下曲線相減（Top - Bottom）與左右曲線相減（Right - Left）。
2. 接續學習 **6.2 圓盤/圓環法**，掌握橫截面面積 $A(x) = \pi r^2$ 或 $\pi (R^2 - r^2)$。
3. 最後掌握 **6.3 柱殼法**，透過展開薄片 $2\pi \cdot \text{radius} \cdot \text{height}$ 處理特定難題。
