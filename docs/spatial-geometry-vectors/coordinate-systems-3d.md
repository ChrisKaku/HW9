# 三維直角坐標系與基本曲面 (3D Coordinate Systems)

> **一句話核心定義**：三維直角坐標系（$\mathbb{R}^3$）由三條兩兩垂直且相交於原點的坐標軸（$x, y, z$）構成，利用序三組 $(x, y, z)$ 唯一確定空間中的每一點，並以此建立距離公式與曲面方程式。

## 核心概念與運作原理

- **右手定則（Right-Handed System）**：
  - 右手四指從正 $x$ 軸彎向正 $y$ 軸，大拇指指向即為正 $z$ 軸向上方向。
- **坐標平面與空間劃分**：
  - 三個基本坐標平面：$xy$-平面（$z = 0$）、$xz$-平面（$y = 0$）、$yz$-平面（$x = 0$）。
  - 三平面將空間劃分為**八個卦限（Octants）**，第一卦限滿足 $x > 0, y > 0, z > 0$。
- **維度幾何對應**：
  - 點：零維幾何物件。
  - 曲線：一維幾何物件（空間直線為特例）。
  - 曲面：二維幾何物件（方程式 $F(x,y,z) = 0$ 在三維中表曲面；平面為特例）。

| 方程式類型 | 二維空間 $\mathbb{R}^2$ 中幾何圖形 | 三維空間 $\mathbb{R}^3$ 中幾何圖形 |
| :--- | :--- | :--- |
| $x = 2$ | 鉛直線（Line） | 平行於 $yz$-平面的垂直平面（Plane） |
| $x^2 + y^2 = 4$ | 圓心在原點、半徑為 2 的圓 | 軸為 $z$ 軸的鉛直圓柱面（Vertical Cylinder） |
| $(x-a)^2 + (y-b)^2 + (z-c)^2 = r^2$ | （不適用於二維） | 球心在 $(a, b, c)$、半徑為 $r$ 的球面（Sphere） |

## 公式與範例

### 1. 三維空間兩點距離公式
空間中兩點 $P(x_1, y_1, z_1)$ 與 $Q(x_2, y_2, z_2)$ 之間的直線距離：

$$|P - Q| = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$

### 2. 球面標準方程式
球心為 $C(a, b, c)$、半徑為 $r > 0$ 的球面滿足：

$$(x - a)^2 + (y - b)^2 + (z - c)^2 = r^2$$

### 3. 典型範例（Worksheet 12.1 範例）
**題目**：描述方程式 $x + y = 2$ 在 $\mathbb{R}^3$ 中的幾何圖形。
**解答**：
方程式中缺少變數 $z$，表示對任意實數 $z$，點 $(x, 2-x, z)$ 皆落在曲面上。這是一個**鉛直平面（Vertical plane）**，垂直於 $xy$-平面，並交 $xy$-平面於直線 $x + y = 2, z = 0$。

## 常見誤區與重點提醒

- **維度混淆**：看到 $x = 2$ 或 $y = 3x$ 切勿直接答直線！在 $\mathbb{R}^3$ 空間中，單一方程式通常代表**二維曲面或平面**，而非直線。
- **不等式區域判定**：如 $x^2 + y^2 \le 8, z = -1$，此為位於水平面 $z = -1$ 上的**實心圓盤**，而非三維立體。
